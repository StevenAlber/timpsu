# Timpsu.ee — maailmaklassi lasteversioon

## Eelvaade
Ava `index.html` Macis Safari või Chrome'iga.

## GitHub Pages
1. Loo GitHubis uus repository.
2. Laadi kogu selle kausta sisu repo juurkausta.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Kui leht töötab, lisa GitHub Pagesis custom domain `timpsu.ee`.

## Enne avaldamist
Muuda failis `script.js` väärtus:

```js
const FORM_LINK = "FORM_LINK_HERE";
```

oma Google Formi päris lingiks.

## Visuaalne süsteem
- Põhivärvid: elus metsaroheline, mururoheline, taevasinine, mustikasinine, marjaroosa, päikesekollane.
- Timpsu tunnused: päris siili kuju, sinised ümmargused prillid, sinine sall, pliiats ja vihik.
- Keelatud: beež-kuldne luksuskujundus, tume mets, töövihiku tunne, geneeriline AI-lasteäpp.
